# SISFAC 10.6.4

## Titulo sugerido

`SISFAC 10.6.4`

## Descripcion corta

Release de mantenimiento enfocada en estabilidad de facturacion, talonarios e importacion/exportacion por Excel.

## Notas para GitHub Release

### Incluye

- correccion de numeracion ascendente de facturas por talonario
- uso correcto del ultimo numero disponible del rango
- validaciones para evitar talonarios invalidos
- mejoras en importacion y exportacion de Excel
- correccion del modal de importacion en Ajustes
- README simplificado para usuarios finales

### Recomendado para el usuario

1. Hacer un backup antes de actualizar.
2. Descargar el instalador correspondiente a su sistema.
3. Instalar la nueva version.
4. Verificar importacion/exportacion de Excel si ya usa ese flujo.

### Archivos sugeridos para adjuntar

- instalador `.exe` para Windows
- paquete `.deb` para Linux

### Observacion

Si el usuario ya trabaja con talonarios, esta version es importante porque corrige la secuencia de numeracion y su consistencia.
